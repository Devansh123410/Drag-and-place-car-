# Drag-and-place-car-
A wireless robotic car capable of picking up, dragging, and placing objects remotely. This project combines custom 3D-modeled mechanics with smart wireless control circuitry, fully simulated and tested before physical assembly.
🚀 Key Features

Wireless Remote Control: Seamless wireless operation for driving and mechanical manipulation.
Drag & Place Mechanics: Custom-designed gripper/arm assembly built to securely grasp and move objects.
Precision CAD Design: Optimized chassis and moving parts for strength and weight distribution.
Virtual Prototype Testing: Fully simulated firmware and circuitry to ensure reliability before hardware deployment.
